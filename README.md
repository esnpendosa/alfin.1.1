# AgroVoice AI 🌱

> Kabar pertanian langsung dari lahan. Platform informasi, berita, dan galeri inovasi agrikultur Indonesia.

## 🚀 Live Demo
Website ini aktif dan dapat diakses langsung melalui GitHub Pages:
👉 **[https://esnpendosa.github.io/alfin.1.1/](https://esnpendosa.github.io/alfin.1.1/)**

---

## 📖 Fitur Utama

- **Beranda Interaktif**: Sorotan berita unggulan, kartu berita terbaru, galeri dokumentasi foto/video, dan lokasi kantor pusat terintegrasi peta.
- **Katalog Berita**: Halaman daftar semua berita dengan filter kategori (Semua, AgriPerikanan, dll).
- **Detail Berita Dinamis**: Membaca artikel lengkap beserta foto dokumentasi dan metadata tanggal terbit.
- **Galeri Dokumentasi**: Grid dokumentasi kegiatan pertanian, peternakan, dan perikanan di lapangan.
- **Sub-halaman Sektor**:
  - AgriPerikanan (`uploads/web/agri-perikanan.html`)
  - AgroPertanian (`uploads/web/1794879347_agropertanian.html`)
  - AgroPeternakan (`uploads/web/1794879300_agropeternakan.html`)
- **Statis & Cepat**: 100% Client-side HTML, CSS, dan JavaScript tanpa memerlukan backend database server MySQL, siap di-host langsung di GitHub Pages.

---

## 🛠️ Cara Menjalankan Secara Lokal

Cukup buka file `index.html` langsung di browser favorit Anda, atau jalankan web server lokal sederhana:

```bash
# Menggunakan Python
python -m http.server 8000

# Menggunakan PHP built-in server (opsional)
php -S localhost:8000
```
Buka `http://localhost:8000` pada browser.
